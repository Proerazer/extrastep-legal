1. Introduction

ExtraStep is an independent Discord moderation bot operated under Erazable. It provides moderation functionality to participating Discord servers, including a shared global ban system.

This Privacy Policy explains what information ExtraStep accesses, how that information is used, what is stored, and how individuals can request the removal or correction of their information.

ExtraStep is not affiliated with or endorsed by Discord Inc.

2. Information We Process

**2.1. Reported users**

When a Discord user is reported through ExtraStep, the following information may be accessed during the review process:

- Discord user ID.
- Username.
- Profile picture.
- Public profile description and other profile information made available through Discord.
- Publicly available account connections, where accessible.
- Information and evidence submitted within the report ticket.

This information is used to evaluate the report.

ExtraStep does not permanently store the reported user's profile information or submitted evidence in its own database.

**2.2. Reporting users**

ExtraStep accesses the reporting user's Discord username for identification within the reporting process.

ExtraStep does not permanently store the reporting user's username in its own database.

**2.3. Approved global bans**

When a report is approved by an authorized ExtraStep moderator, the reported user's Discord user ID is added to ExtraStep's global ban database.

No usernames, profile pictures, report evidence, or detailed moderation histories are stored alongside the approved ID.

Rejected reports do not result in an entry in the global ban database.

3. Purposes of Processing

ExtraStep processes information to:

- Receive and review moderation reports.
- Evaluate alleged violations of Discord's rules.
- Maintain its approved global ban database.
- Enforce approved global bans across participating Discord servers.
- Review appeals and correct or remove global ban records.

4. Storage and Hosting

ExtraStep maintains a local database containing only the Discord user IDs of accounts approved for global banning.

The database is stored within the environment hosting the application. ExtraStep does not maintain separate permanent archives of report evidence, reporting users' information, or moderation ticket contents.

ExtraStep does not intentionally maintain persistent application logs containing user information.

5. Report Tickets and Evidence

Reports are reviewed through Discord ticket channels.

After the review process, the ticket is closed using ExtraStep's built-in ticket-closing command, which deletes the associated Discord channel.

ExtraStep does not separately archive the submitted evidence or ticket contents in its own database.

Deletion of a Discord channel does not necessarily imply immediate deletion of all information retained independently by Discord under its own policies.

6. Global Ban Enforcement

When a reported account is approved for global banning, its Discord user ID is added to ExtraStep's database.

ExtraStep uses this database to carry out automatic ban actions in participating Discord servers.

Participating servers receive the resulting moderation action rather than a separate copy of ExtraStep's global ban database.

The initial decision to approve a report is made through human review.

7. Data Retention and Removal

Approved Discord user IDs remain in ExtraStep's global ban database until a successful appeal or manual removal.

ExtraStep currently does not apply an automatic expiration period to these records.

This retention practice must be assessed against applicable data protection requirements, including the principles of storage limitation and data minimization.

Where a global ban is overturned, the corresponding Discord user ID is removed from ExtraStep's database.

Removing an ID from the global database does not necessarily reverse bans previously applied within individual Discord servers.

8. Appeals and Reversal of Enforcement

Users affected by ExtraStep's global ban system may appeal a moderation decision through the official support server or designated contact email.

When an appeal is approved, the affected Discord user ID is removed from ExtraStep's global ban database.

Removal prevents further enforcement based on that record. ExtraStep also initiates unban actions across participating servers to reverse bans previously imposed through its global moderation system.

Successful reversal depends on the bot remaining present in the relevant servers and possessing the necessary permissions.

Appeals and requests concerning personal data may be submitted through the same contact channels.
